# ⛰️ 십계명 메타버스 (Ten Commandments Metaverse)

주일학교 어린이들이 시내산과 광야를 탐험하며 모세의 십계명 돌판을 완성하는 실시간 인터랙티브 2D 교육 메타버스 플랫폼입니다.

---

## 🌟 주요 특징

1. **대형 화면(교사) & 모바일(학생) 맞춤형 인터페이스**:
   - **교사 화면 (PC / 빔프로젝터)**: 광야 전체를 한눈에 관제하는 와이드 조망 뷰, 참가용 실시간 QR코드 플로팅 창, 게임 시작/대기 전환 제어, 퀴즈 관리자 메뉴 제공.
   - **학생 화면 (스마트폰 / 태블릿)**: 세로 모드 차단 및 가로 모드 자동 감지, 내 캐릭터 중심의 클로즈업 팔로우 카메라, 터치 가상 조이스틱 조작.

2. **나만의 2D 픽셀 아바타 꾸미기**:
   - 성별, 피부색, 3종 헤어스타일, 머리색, 성경 시대 의상 및 소품(모자/선글라스), 신발을 조합하여 아바타를 생성.
   - 머리 위에 학생의 실시간 닉네임 명찰이 표시됩니다.

3. **실시간 P2P 멀티플레이어 (WebRTC PeerJS)**:
   - 복잡한 백엔드 서버 설치 없이 브라우저 간 직접 연결(P2P)로 여러 학생이 동시에 접속하여 함께 뛰어놉니다.
   - 중간에 접속한 학생도 교사의 방 상태(퀴즈 데이터, 해결된 돌판, 진행 모드)를 그대로 상속받습니다.

4. **2대 게임 모드 지원**:
   - **🤝 협동 모드 (우리 반 함께 완성)**: 반 친구들이 10개 계명을 나누어 찾아 해결하면 공동 돌판이 채워지며, 10개가 모두 모이면 모세 제단에서 다 함께 봉헌식을 진행합니다.
   - **🏆 개인전 모드 (선착순 랭킹 레이스)**: 각자가 10개의 계명을 모두 찾아 완성한 순서대로 실시간 순위와 기록이 매겨집니다.

5. **자체 Web Audio API 사운드 신디사이저**:
   - 외부 대용량 음원 파일 없이 순수 웹 코드로 평화롭고 신비로운 시내산 BGM과 팡파레, 상호작용 효과음을 즉석 합성 재생합니다.

6. **교사용 퀴즈 관리 & 클라우드 저장 시스템**:
   - OX 퀴즈 및 2~4지선다형 객관식 문제 편집 지원.
   - **교사 전용 접속코드(개별 비밀번호 직접 등록)** 인증을 통해 집에서 만든 퀴즈 세트를 클라우드에 안전하게 저장하고, 교회 PC에서 파일 없이 원클릭으로 불러올 수 있습니다.
   - 카카오톡 전송용 **한 줄 퀴즈 설정 코드(Base64)** 및 **JSON 백업/불러오기**도 함께 제공됩니다.

## 🚀 빠른 시작 및 실행 방법

### 1. 실행 환경 요구사항
- Python 3.8 이상 (또는 임의의 로컬 웹 서버)
- 최신 웹 브라우저 (Chrome, Edge, Safari 등)

### 2. 로컬 실행 방법
```bash
# 프로젝트 폴더로 이동
cd projects/십계명메타버스

# 로컬 개발 서버 실행
python server.py
```
- 서버가 켜지면 터미널에 로컬 접속 주소(`http://localhost:8000`)와 **같은 와이파이(LAN) IP 주소**가 표시됩니다.

### 3. 교사 및 학생 접속 방법
1. **교사 (PC / 프로젝터)**:
   - 브라우저에서 `http://localhost:8000` 접속 (또는 배포 웹사이트 접속)
   - 상단 `📱 방 QR코드` 창의 `방: SINAI-777 ⚙️` 버튼을 눌러 **우리 교회/학급 고정 방 코드**(예: `우리교회`, `예닮초등부`, `SINAI-777`)를 자유롭게 설정할 수 있습니다. 한 번 설정하면 브라우저에 영구 저장됩니다.
   - 학생들을 맞이할 대형 QR코드를 띄워둡니다.
2. **학생 (스마트폰 최초 1회 접속 & 홈 화면 앱 추가)**:
   - 카메라 앱으로 교사 화면의 QR코드를 스캔하여 접속합니다.
   - 사파리 하단 **공유 버튼( ⬆️ ) ➔ [홈 화면에 추가]**를 눌러 아이폰 바탕화면에 앱 아이콘을 만듭니다.
   - **다음 주부터는 QR코드를 찍을 필요 없이**, 아이폰 바탕화면의 **「십계명 메타버스」 앱만 누르면 선생님 방으로 자동 직행**하며 상하단 바 없는 **완전한 전체화면**으로 실행됩니다!
3. **게임 시작**:
   - 학생들이 모두 입장하면 교사가 상단의 `▶️ 게임 시작!` 버튼을 눌러 퀴즈 상호작용을 활성화합니다.

## ☁️ 클라우드 퀴즈 관리 가이드

### 교사 전용 접속코드 관리
- **최초 등록**: 최초 클라우드 메뉴 클릭 시 선생님께서 사용할 비밀번호(4자리 이상)를 직접 입력하여 등록합니다.
- **코드 변경**: 상단 `✏️ 퀴즈 편집` ➔ `🔑 교사 접속코드 관리`에서 언제든지 비밀번호를 안전하게 변경할 수 있습니다.

### 집에서 퀴즈 만들고 교회에서 불러오기
1. **집에서**:
   - `✏️ 퀴즈 편집`을 열고 계명별 문제(OX 또는 객관식)를 수정합니다.
   - `💾 클라우드에 저장`을 누르고 교사 접속코드를 입력한 뒤 퀴즈 세트 이름을 저장합니다.
2. **교회에서**:
   - 교회 PC에서 접속 후 `✏️ 퀴즈 편집` ➔ `☁️ 클라우드 퀴즈 목록` 클릭
   - 교사 접속코드를 입력하면 저장해둔 퀴즈 세트 목록이 나타나며 `📥 불러오기` 버튼 하나로 즉시 적용됩니다.

## 📁 프로젝트 파일 구조

```
십계명메타버스/
├─ index.html                     # 메인 엔트리 웹페이지
├─ server.py                      # Python 로컬 웹 서버 (IP 자동 출력)
├─ README.md                      # 프로젝트 설명 및 매뉴얼
├─ PROJECT.md                     # 프로젝트 정의 및 규칙
├─ docs/                          # 프로젝트 작업 및 결정 기록
│  ├─ TASKS.md
│  └─ DECISIONS.md
├─ 공유용/                         # 배포용 최신 실행 파일 복사본
└─ src/
   ├─ style.css                   # 게임 및 반응형 UI 스타일시트
   ├─ main.js                     # 게임 메인 루프 및 이벤트 오케스트레이션
   ├─ controls/
   │  └─ inputController.js       # 키보드 및 모바일 터치 조이스틱 입력 처리
   ├─ engine/
   │  ├─ camera.js                # 2D 줌 & 팔로우 카메라 (여백 방지 Clamping)
   │  ├─ soundEngine.js           # Web Audio API 자체 신디사이저 엔진
   │  └─ world.js                 # 시내산/광야 맵 렌더러 및 30개 후보 비석 스폰
   ├─ data/
   │  └─ commandmentsData.js      # 십계명 OX/객관식 퀴즈 데이터 및 인코더
   ├─ services/
   │  └─ cloudQuizService.js      # 클라우드/로컬 퀴즈 동기화 및 교사 인증 서비스
   ├─ network/
   │  └─ networkManager.js        # PeerJS WebRTC P2P 호스트/클라이언트 동기화
   └─ components/
      ├─ avatarCustomizer.js      # 2D 픽셀 아바타 꾸미기 룸
      ├─ leaderboardWidget.js     # 협동 돌판 현황 및 개인전 랭킹 위젯
      ├─ quizEditorModal.js       # 교사용 퀴즈 편집기 및 클라우드 패널
      ├─ quizModal.js             # 학생용 퀴즈 풀이 모달 (OX / 객관식)
      └─ tabletModal.js           # 십계명 돌판 확인 및 수료증 세레머니
```
